# Job Application Tracker

A simple command-line application built with Python to help users organise and manage their job applications.

This is my first independent Python project, created to practise the fundamental programming concepts I've learned.

## Features

- **Add Application:** Record a company name, job role, and application status.
- **View Applications:** Display all recorded applications.
- **Search Application:** Find an application using the company name.
- **Delete Application:** Remove an application from the tracker.
- **Interactive Menu:** Navigate between features and exit the application.

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Download or clone this repository.
2. Ensure Python 3 is installed on your computer.
3. Open a terminal in the project directory.
4. Run:

```bash
python3 job_application_tracker.py
```

5. Follow the on-screen menu to manage your applications.

## Concepts Practised

- Python functions and parameters
- Lists and dictionaries
- Loops and conditional statements
- User input and output
- List methods
- Return statements

## Limitations

This version stores application records in memory, so records are not preserved after the program closes. Persistent storage and improved input validation may be added in future versions.
